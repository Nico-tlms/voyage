# VoyageHub

Landing page statique pour un site d'affiliation voyage qui rassemble les meilleurs bons plans du web.

## Aperçu

- Hero section avec formulaire de recherche intelligent.
- Offres dynamiques générées en JavaScript à partir d'une sélection de partenaires.
- Sections inspiration, destinations tendance, témoignages et inscription newsletter.
- Design responsive avec typographie Poppins et dégradés modernes.

## Utilisation

Ouvrez `index.html` dans votre navigateur pour découvrir l'expérience VoyageHub.
